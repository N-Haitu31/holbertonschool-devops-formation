# DevOps Culture & Git collaboration

This project offers a one-day immersion into DevOps culture and Git collaboration, where the goal isn't to memorize definitions but to build essential reflexes (clean Pull Requests, conflict resolution, blameless post-mortems) through the CALMS principles, DORA metrics, GitHub Flow, and Conventional Commits.

Task 4 (4-postmortem.md) applies this directly: a blameless post-mortem of
a fictional incident, linking each systemic cause to the DORA metric it
degrades.
