# Docker Fundamentals

## About
This project is a hands-on immersion into Docker: building images, running and debugging containers, and fixing real (broken) apps to understand exactly where containers succeed or fail.

## What this project covers
- Running and inspecting containers (pull, run, exec, logs, stop, rm)
- Writing a Dockerfile and building an image
- Debugging and fixing a broken Flask app running in a container
- Debugging and fixing a broken Express (Node.js) app running in a container
- Interacting with a running container (exec into it, inspect logs, check the filesystem from inside)
